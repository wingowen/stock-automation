# 第一章：聪明钱解读市场的工具是什么？

## Core Idea

价格、成交量、走势速度是聪明钱解读市场的三个基本要素，其理论基础是供求关系——专业交易员从价量细节中读出CM（主力机构）的真实意图，而非依赖技术指标这种"表象"。

## Frameworks Introduced

- **聪明钱的看盘顺序（五步法）**
  - When to use: 每次面对走势图时（替代看技术指标产生信号的习惯）
  - How: ①背景（牛/熊/震荡区）→ ②价量形态（蜡烛长度、成交量高度、变化速度）→ ③价量形态的性质（走势强弱及后果）→ ④结论/预测（供求关系判断CM意图）→ ⑤措施和行动（进场/出场/收紧止损）

- **CM观察走势的三大原则**
  - When to use: 判断趋势动力、趋势反转、走势停止时
  - How:
    - **供求关系原则**：趋势动力来自供求不平衡。已持仓时，供求变化决定立刻离场（否定判断）或持有（支持判断）
    - **因果关系原则**：趋势反转前必须有准备过程（如吸筹）。"因"=准备过程，"果"=趋势。避免盲目抄底
    - **努力和结果原则**：努力=成交量，结果=价格进展幅度。成交量扩大但价格范围很窄=努力没产生结果=停止行为

- **供求关系判断支撑/阻力有效性**
  - When to use: 价格回到支撑或阻力位时
  - How: 支撑位看是否有大量买单吸收卖盘（测试蜡烛须小蜡烛=供应枯竭）；阻力位看回落力度（回落量小=卖单少=不会威胁突破）

- **识别供应/需求扩大**
  - When to use: 判断震荡区、阻力位、熊市趋势转折
  - How: 震荡区需求扩大=右手边相对长阳线+扩大量；供应扩大=顶部放量和上影线；熊市需求扩大=天量+超长阴线=恐慌抛售（SC）

## Key Concepts

- **CM（主力机构）**：掌握大资金的人或机构，能移动市场，利用各种优势左右市场
- **恐慌抛售/超卖高潮（SC）**：下降趋势中潮水般的恐慌抛售，极宽振幅+超高成交量，标志下降趋势结束或接近结束
- **死角**：支撑/阻力位上蜡烛高点不断降低、低点不断升高，波动越走越窄，预示价格即将大幅波动
- **震仓（Shakeout）**：震荡区中故意使价格下降或上涨，激起公众平仓而投机者接盘。分普通震仓和终极震仓
- **冰线**：上升趋势中最后一道防线，冰线上的买单因突破被套牢
- **供应线**：下降通道的上轨，假设每次价格到此处都有大量卖单流入压价
- **垂直需求柱/垂直供应柱（VSB）**：垂直需求柱=放量长阳，底部形成支撑区；垂直供应柱=供应完全控制市场
- **上冲回落（UT, Upthrust）**：突破阻力线后又收在阻力线之下，主力迅速吃掉空方止损单后任价格下跌
- **JOC（Jump over the Creek）**：SOS信号的一种，价格强烈上涨突破前期关键阻力或区间上边界
- **SOS/SOW**：SOS=强势信号（需求控制市场）；SOW=弱势信号（供应控制市场）
- **抢购高潮（BC, Buying Climax）**：上升趋势结束时公众疯狂买入形成的高潮，成交量明显增加且振幅变大
- **停止行为（SOT）**：牛市中放量滞涨、熊市中放量滞跌统称，是走势即将停止的信号

## Mental Models

- 当看到技术指标（MACD/均线）时，把它当作"表象"，把背后的供求关系当作"本质"——公众花时间调参数是徒劳的
- 把吸筹过程看作"因"，把后续趋势看作"果"——没有准备过程的趋势不会持续太久
- 当看到成交量扩大但价格进展很小时，把它看作"努力没有结果"——大量卖单流入但价格不跌=需求吸收了供应
- 当趋势线与水平阻力线交叉形成死角时，把它看作"行情即将有大动作"的预警

## Anti-patterns

- **用均线/黄金分割等指标线单独代表支撑/阻力**：市场对这些线一无所知，支撑/阻力的本质是某一价位的供求关系
- **看到大跌就立刻抄底**：没等到吸筹过程（"因"）结束，会抄在半山腰被套
- **突破时立刻进场与公众为伍**：突破是公众行为，应等小蜡烛低量回调再进
- **在牛市中看到超长阳线和放量就追多**：那可能是CM利用公众疯狂的出货手段（抢购高潮）
- **用情绪和希望否定市场本质行为**：抢反弹后看到供应继续主导仍不出场，会被深套

## Worked Example

**图1-3 熊市末期吸筹结束的完整判断流程**

背景：熊市，价格进入震荡区。

1. A到B快速下跌=超卖行为；蜡烛B成交量到顶峰=**恐慌抛售（SC）**，需求正在吸收抛盘
2. 蜡烛1：高低范围超大但上影线+超大成交量=反弹遇强大供应，趋势仍熊市
3. 蜡烛2：阻力位停滞（SOT）+扩大成交量=顶部供应超过需求
4. 趋势线BC与阻力线交叉=**死角**，稍稍努力就能突破
5. 价格突破BC后迅速下跌=怀疑是**震仓**。蜡烛7到达支撑区时高低范围大幅缩小但成交量没缩小=**停止行为**
6. 最后一根阳线=需求全部吸收供应，CM已收购完下方股票 → **吸筹结束，可以进场买入**

## Key Takeaways

1. **永远先看背景，再看形态**：脱离背景的形态毫无意义
2. **供求关系是唯一根基**：任何判断都要以供求关系理论为基础
3. **反转必须有准备过程**：没有"因"就不要追"果"
4. **努力和结果在支撑/阻力位最实用**：支撑位放量但价格范围窄=停止行为
5. **不与公众为伍**：最安全进场点是突破后小蜡烛低量回调时
6. **死角是黄金预警**：只需小力量就能突破，是提前进场好时机
7. **培养无指标看盘能力**：仅从价格和成交量细节读出供求关系
