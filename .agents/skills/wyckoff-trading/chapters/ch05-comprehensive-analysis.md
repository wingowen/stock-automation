# 第五章：综合分析——交易机会，进场点，危机管理

## Core Idea

观察走势图必须深入价格背后而非表象：先建立"理论基础"（如"阻力上的卖盘被需求全部吸收"），再在图上寻找能确认该理论的价量行为——这就是**市场本质交易法**：理论基础先行，价量确认为证，背景判断为纲。

## Frameworks Introduced

- **市场本质交易法**
  - When to use: 每次分析走势时
  - How: 先提出理论基础 → 在图中找能够确认理论基础的价量行为 → 形成判断 → 制定交易计划+危机管理计划

- **时间框架分析（多时间框架）**
  - When to use: 日线反转前，或日线信号模糊时
  - How: 日线看大背景与趋势；小时线提前捕捉需求/供应进入的细节（"日线出现反转之前，小时线会提前出现上涨行为"）

- **无需求反弹交易法**
  - When to use: 供应控制的大背景下，价格反弹至支撑/阻力时
  - How: 观察反弹是否"小蜡烛+小成交量+低收盘"→若是则做空（阻力位）或离场（支撑位）

- **冰线交易法**
  - When to use: 熊市背景，价格反弹测试冰线
  - How: 问"趋势是什么"→若回调低量在冰线之上结束→做多；第一支撑=冰线，第二支撑=突破柱低点，第三支撑=1~3的50%；超过50%则熊市恢复

- **SOT/停止行为交易法**
  - When to use: 上涨/下跌幅度递减时
  - How: 识别SOT → 等待跟随 → 若阴线伴随扩量跟随，停止行为确认 → 反向操作

- **跳跃小溪交易法（JOC）**
  - When to use: 价格放量跳离震荡区间
  - How: JOC=进场预备信号 → 等待低量回测跳离点 → 回测无供应+停止行为 → 买入；放量回测则放弃

- **弹簧效应交易法（Spring）**
  - When to use: 价格突破支撑后迅速回归
  - How: 需区分背景——需求背景下Spring是进场点；供应背景下Spring经常失败，是做空信号，必须等二次测试

- **相对强弱分析选股法**
  - When to use: 选股阶段
  - How: 打印大盘日图 → 选强势板块龙头 → 逐只与大盘对比 → 大盘创新低时个股坚挺支撑（回调<50%）+大盘反弹时个股涨幅更大=目标股 → 再对个股做吸筹/JOC分析

- **50%回调原则**
  - When to use: 判断回调是否威胁趋势
  - How: 回调<50%=正常回调，趋势未受威胁；回调>50%=趋势可能反转

- **死角交易**
  - When to use: 趋势线与阻力线交叉位置
  - How: 死角=供求相持 → 突破死角后价格行为剧烈 → 死角中需求>供应则向上突破，反之向下

## Key Concepts

- **理论基础**：对市场行为的因果假设（如"供应耗尽，需求占上风"），必须在图上找到价量证据确认
- **停止行为**：价格上涨/下跌遇阻的价量信号，如高量缩短的高低价差+高位收盘，或SOT
- **SOT（Sign of Trend）**：上涨/下跌幅度递减，属于价格停止行为
- **JOC（Jump Over Creek）**：放量扩价差跳离震荡区，是需求战胜供应的确认信号
- **冰线（Ice Line）**：CM在派发区设立的供应区/阻力线，破冰意味着CM不再防守
- **无需求反弹**：小蜡烛+小成交量+低收盘的反弹，买方无力，预示价格续跌
- **bag holding（口袋接盘）**：威科夫术语，买方在下跌中张口袋接盘，成交量扩大但价格跌幅很小
- **跟随（Follow-through）**：停止行为/SOT/Spring后下一根蜡烛的方向与量能，决定信号是否成立

## Mental Models

- 当判断趋势反转时，把"理论基础→价量确认→判断"当作三段式验证：先有理论，再找证据，最后下结论
- 把市场看作两军战场：进攻方（需求）失地后必须等"大量援军"（新需求）才能扭转
- 把CM看作主力机构，把自己看作跟随者：读懂CM意图并在消息公布前跟随行动
- 当价格突破重要位置时，把"回调1~3根蜡烛"当作默认预期：突破后回调的价量性质决定方向

## Anti-patterns

- **熊市中随意抄底**：铁律——熊市中不能随意抄底，必须等右手边需求占上风
- **见Spring就抄底**：供应背景下Spring经常失败
- **追突破买入**：公众追突破常被CM利用，需等低量回测确认
- **只看形态/指标，不看大背景**：判断必须基于市场倾向而非某个形态或指标
- **不等跟随就行动**：停止行为、UT、Spring后必须有跟随确认
- **不设危机管理计划**：每个交易计划必须同时配备危机管理——出场条件要预先量化
- **把需求匮乏等同于趋势反转**：单靠需求匮乏不能把牛市转为熊市，必须在供应扩大的背景下

## Worked Example

**时间框架分析案例（2009年3月标普期货）**

背景：熊市轨道明显。

- **小时图**：蜡烛1放量急涨，抹掉前5根跌幅；后续无量回调确认是需求所致。蜡烛2高开放量阳线巩固需求，蜡烛3供应淹没需求。蜡烛4跌破当天低点逼抄底者清仓，但成交量立刻消失——供应枯竭
- **日线**：蜡烛A起连续5根贴超卖线无需求；看不出上涨迹象，但小时图已确认需求进入
- **交易计划**：进场买入，止损放日线最低点下面一个点，第一目标供应线
- **危机管理**：若接下来日线阴线且成交量增长=供应恢复力量，无论亏赚立刻出场

## Key Takeaways

1. **每次分析先问"理论基础是什么"，再找价量证据，最后判断**——市场本质交易法的核心顺序
2. **先问"趋势是什么/背景由谁控制"**，回答了这个问题，操作方向就有了
3. **熊市反转必须等右手边需求占上风**
4. **供应背景下的Spring是做空信号，不是抄底信号**
5. **JOC后必须等低量回测才能进场**；放量回测=放弃计划
6. **每个交易计划必须配套危机管理**：预先量化出场条件，触发即执行，不论亏赚
7. **多时间框架交叉验证**：日线看背景，小时线看细节
