# 第三章：威氏逃顶策略——如何识别主力的派发意图

## Core Idea

市场到顶的理论根据是供应开始大量进入市场、需求随后耗尽、最终供应完全控制市场；通过价量关系识别CM的派发意图与谎言，在派发四个阶段中找到全身而退的时点，并在SOW确认后建立空仓。

## Frameworks Introduced

- **派发四阶段框架（核心骨架）**
  - When to use: 判断牛市是否结束、是否进入派发、是否可做空的全流程
  - How: 按顺序识别——
    1. 第一阶段：牛市结束（初次供应→抢购高潮→自然回落→二次测试，成功的二次测试标志牛市终止）
    2. 第二阶段：CM设立派发区并引诱公众接盘（建立支撑夹板、利用媒体与急涨造势）
    3. 第三阶段：测试阶段（UT与SOW），确认派发并接近尾声——此阶段最重要
    4. 第四阶段：SOW出现，市场进入熊市

- **SOT（突破幅度递减）**
  - When to use: 牛市中识别需求开始匮乏的预警
  - How: 找有深度回调的上升波，比较其顶点距离；若连续反弹无法触及超买线即折返= SOT。出现后缩紧止损，等支撑线被突破即离场

- **50%原则（牛熊分界线）**
  - When to use: 判断回调是强势还是弱势、趋势是否受威胁
  - How: 以上升波幅度的50%为基准；回调未破50%且蜡烛与成交量缩小=供应耗尽、牛市继续；回调超过50%且扩量=供应扩大、牛市受威胁

- **上冲回落（UT, Upthrust）**
  - When to use: 派发第二/第三阶段，测试需求是否枯竭、寻找做空点
  - How: 价格试图突破震荡区顶部，1-3根K线内跌回区间；UT后必须有跟随（放量下挫）才能证明供应强劲。做空进场点之一

- **SOW（弱势出现/熊市初显）**
  - When to use: 确认派发、确认熊市开始
  - How: 放量长阴，必须出现在震荡区右手边才有效；出现后仅是"可能的SOW"，必须经紧接着的无量上涨确认

- **冰线与破冰（Ice Line / Breaking the Ice）**
  - When to use: 判断支撑是否被CM放弃、派发是否完成
  - How: 把派发区底部支撑比作冰线；带量长阴突破冰线=CM撤掉夹板、货已出完；破冰后任何回测冰线的反弹遇供应即为做空点

- **LPSY（Last Point of Supply，最后派发点）**
  - When to use: SOW之后的回测反弹
  - How: SOW之后小成交量、小蜡烛的反弹即为LPSY；最佳做空点，也是出逃的最后一班车

## Key Concepts

- **派发（Distribution）**：CM在高位将吸筹阶段买入的股票卖给公众的过程，分四阶段，结束时牛市转为熊市
- **初始供应（Initial Supply）**：牛市中首次出现大量供应上市的行为，仅为预警非牛市终结
- **抢购高潮（BC, Buying Climax）**：公众在贪婪驱动下疯狂接盘，天量创新高且上涨角度趋垂直，是CM派发的高峰
- **自然回落与二次测试**：抢购高潮之后的市场行为；二次测试成功（量能不及抢购高潮）标志牛市终止
- **UT（上冲回落）**：价格试图突破震荡区顶部但1-3根K线内跌回，是CM测试需求、扫止损的策略
- **SOW（弱势出现）**：放量长阴、必须出现在震荡区右手边的熊市信号，需经无量上涨确认
- **冰线**：派发区底部支撑的形象比喻；破冰=CM放弃护盘
- **LPSY（最后派发点）**：SOW之后小蜡烛小成交量的回测反弹点，最佳做空点

## Mental Models

- 把支撑看作冰线：价格跌破冰线就像人跌落冰层——再向上努力碰到厚冰（供应）就会再沉底
- 把CM看作导演：用媒体造利好、用急涨挑动公众兴奋、用震仓与疲劳战术驱离跟风者
- 当价格应该涨却没涨时，把它当作警告：停止行为，需警觉供应在隐蔽扩大
- 把派发看作吸筹的镜像：派发时间短于吸筹（公众心甘情愿买 vs 恐惧被迫抛）
- 把震荡区判断看作"等右手边SOW/SOS"：不预判方向，耐心等右手边出现信号再决策

## Anti-patterns

- **熊市中抢反弹**：违背顺势而为，风险远大于盈利
- **盲目抄底（尤其在低位派发区）**：低位派发常被误判为做底
- **单凭图形交易（如见头肩顶就做空）**：失败率高的原因不在图形而在背后供求关系
- **教条地要求正好回调到50%**：50%只是第一信息，必须结合蜡烛与成交量判读
- **震荡区内急于交易**：派发未确认前在震荡区内交易是赌方向
- **持仓幻想、不止损**：当上升趋势线被带量突破，无论盈亏必须离场

## Worked Example

**2015年中国股指——CM离场策略**

背景：上证2015年5-6月见顶过程。

关键序列：
1. **趋势线速度**：5月19-27日仅7个交易日涨800多点，4月份花一个月才涨800点——趋势线近乎垂直，CM故意挑动公众兴奋
2. **蜡烛2（十字星）**：成交量不减但价格收在中部——供应正在超过需求，最明显的派发信号
3. **自然回落+二次测试**：自然回落末根小蜡烛放量=卖盘继续但有人阻止下跌（停止行为），CM在制造支撑
4. **蜡烛5**：带量突破阻力失败=上冲回落，再次证明供应强劲；其后小蜡烛小成交量回升=成功的二次测试，牛市终止
5. **蜡烛6**：成交量略升但收盘低于前日——CM开始降价满足公众需求
6. **蜡烛6-7暴跌=SOW**，蜡烛7放量突破冰线——市场大跌在即
7. **后续**：蜡烛8再破冰线后超卖反弹，但低量空头回补非需求；蜡烛9长阴高量=潜在SOW，三周反弹无法弥补=努力无结果，确认SOW；蜡烛10放量下挫=熊市真正开始

## Key Takeaways

1. **派发四阶段顺序不能乱**：每个阶段对应不同的出逃/做空窗口
2. **SOT+50%原则+趋势线突破三件套**是判断市场背景的工具组合
3. **任何到顶信号最终都要由供应说话**：UT和SOW是供应的两种表达方式
4. **SOW必须出现在震荡区右手边且需无量上涨确认**
5. **LPSY是最佳做空点**：SOW之后的小蜡烛小成交量反弹
6. **震荡区不预判，等右手边**：出现SOS/弹簧效应=吸筹，出现SOW/带量UT=派发
7. **风控优先于盈利**：初始供应出现即缩紧止损；趋势线被带量突破无论盈亏离场
