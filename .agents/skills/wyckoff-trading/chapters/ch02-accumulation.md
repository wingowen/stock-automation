# 第二章：怎么知道主力机构开始接盘了

## Core Idea

熊市终止的本质是"需求扩大后供应逐渐耗尽"，判断底部不能用情绪或消息，必须通过价量行为识别CM吸筹的四阶段过程，并在**吸筹右手边、供应枯竭被确认后**才能低风险介入。

## Frameworks Introduced

- **熊市终止四行为（PS → SC → AR → ST）**
  - When to use: 判断熊市是否真正终止
  - How: 依次确认——①初次支撑（PS，扩大成交量使下跌停止）→ ②恐慌抛售（SC，超长阴线+超高成交量）→ ③自动反弹（AR，不进场）→ ④二次测试（ST，蜡烛与成交量大幅缩小才算成功）

- **吸筹四阶段模型**
  - When to use: 从熊市结束到牛市开始的全程定位
  - How:
    - 第一阶段：PS/SC/AR/ST，供应大于需求但需求在吸收
    - 第二阶段：震荡区拉锯，CM控制价格上涨以低价收购，使用"疲劳战术"
    - 第三阶段：测试供应（终极震仓/弹簧效应），确认是吸筹而非再派发
    - 第四阶段：SOS+测试 或 JOC+测试，进入牛市

- **三个进场位置（震荡区右手边原则）**
  - When to use: 吸筹确认后选择低风险进场点
  - How:
    1. SOS/JOC之后的回测（小蜡烛+低成交量）——最安全
    2. 成功二次测试后在震荡区底部的弹簧效应处进场
    3. 终极震仓中或其后的二次测试进场

- **跳跃小溪交易法（JOC）**
  - When to use: 定位风险最低的进场时机
  - How: 把震荡区顶部供应区比作"小溪"，等待强劲需求柱（长阳+高量）越过小溪，然后等价格缩量回测突破点时进场。回测必须小蜡烛+低成交量，否则JOC失效

- **死角交易法**
  - When to use: 吸筹末期供应枯竭的确认与进场
  - How: 蜡烛在支撑上越来越短，既无新低也无新高（供求都极弱），形成死角时，需求稍扩大即可突破

- **疲劳战术三步法（CM迫使公众割肉）**
  - When to use: 理解震荡区中CM的控盘手法
  - How: ①顶部布置大量卖单控制价格上涨 → ②用冗长枯燥震荡区折磨公众 → ③终极震仓急速穿透所有支撑

## Key Concepts

- **初次支撑（PS, Preliminary Support）**：CM需求首次进场，以扩大成交量暂时阻止价格下跌
- **自动反弹（AR, Automatic Rally）**：恐慌抛售后的空头回补性反弹，不会持续，不可在此抄底
- **二次测试（ST, Secondary Test）**：测试市场是否还有大型清仓行为，成功标准是蜡烛和成交量大幅缩小
- **吸筹（Accumulation）**：CM在震荡区收购公众恐慌抛出的股票的建仓过程
- **终极震仓（Terminal Shakeout）**：吸筹末期CM让价格急速冲破所有支撑，迫使最后一批公众抛售
- **弹簧效应（Spring）**：价格小幅突破支撑后立刻返回上方，CM用以评估突破时供应量
- **LPS（Last Point of Support）**：SOS/JOC后缩量回调形成的最后支撑点，是安全进场点
- **SOT（Shortening of Thrust）**：波峰或波谷之间突破幅度递减，是重要的停止行为

## Mental Models

- 把震荡区顶部看作"充满卖单的小溪"：价格要继续上涨必须找到小溪窄且水流缓处（供应薄弱区），经短暂回调助跑后越过
- 当看到"努力无结果"时用停止行为模型：卖盘大幅增加但价格没有大幅下跌，说明有隐藏需求在吸收
- 把吸筹过程看作"左手边→右手边"的对称结构：左手边不抄底，右手边才寻找进场时机
- 把CM的控盘看作"确认链"：一个行为需要另一个行为确认——PS需SC确认，SC需ST确认，SOS需回测确认

## Anti-patterns

- **"跌得越深越应该抄底"**：基于情绪的赌博判断，没有看到需求进入
- **在自动反弹处抄底**：自动反弹是空头回补，不会持续，容易遭遇震仓
- **在左手边抄底**：熊市第一次反弹尚未经过二次测试确认
- **在震荡区内参与交易**：震荡区是CM控盘最集中处，风险最大
- **SOS后不等待回测就追进**：需求可能无跟随，必须等缩量回调确认
- **进场后看到放量阴线仍不止损**：遇到大量供应应立刻出场

背景：初次支撑后出现恐慌抛售，随后自然反弹突破下降趋势线确认支撑。

关键节点：
- **蜡烛4**：成交量完全消失=供应枯竭；支撑逐渐抬高=CM已提高收购价 → 确认震荡区是吸筹
- **死角形成**：蜡烛越来越短，既无新低也无新高 → 死角交易法进场点
- **蜡烛6（SOS）**：长阳+高量突破死角与阻力 → 确认需求吸收所有浮动供应
- **蜡烛7（LPS）**：价格回测支撑后漂亮反弹 → 安全进场点
- **蜡烛10（JOC）**：提供进场平台
- **蜡烛17（SOS/JOC）+蜡烛18（弹簧效应）**：再次进场平台

确认链：PS→SC→AR→ST（成功）→死角→SOS→LPS→JOC→吸收→SOS/JOC→弹簧效应

## Key Takeaways

1. **必须在震荡区右手边进场**：永远不在左手边抄底
2. **供应枯竭是牛市孕育成熟的前提**：没看到供应枯竭，牛市就不会真正开始
3. **确认链思维**：一个行为需要另一个行为确认，市场是逐渐明朗的过程
4. **进场后必须看到连续递增的价格和成交量**作为牛市确认
5. **底部没有终极震仓或SOS/JOC之一，不要抄底**
6. **疲劳战术识别**：震荡区中每次反弹被打压、反弹高点台阶式下降=CM在吸筹
7. **死角是最佳进场时机**：市场看起来最萧条时，买入风险最低
