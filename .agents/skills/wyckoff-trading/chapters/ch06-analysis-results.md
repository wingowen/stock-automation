# 第六章：综合分析结果

## Core Idea

本章是第五章24个案例的"答案揭晓"，核心教导是：**判断要基于市场倾向而非形态**，且每个判断都必须用后续走势持续验证——失败的二次测试、无跟随的Spring、破冰后无需求反弹，都是出场/反向的硬信号，不可心存侥幸。

## Frameworks Introduced

- **二次测试序列验证**
  - When to use: 第一次测试不符合进场要求时
  - How: 耐心等待新的二次测试 → 每次测试看"小成交量+小高低价差+高收盘" → 符合则分批建仓 → 不符合则继续等，可多次测试

- **OKR（Outside Key Reversal，外部关键反转柱）**
  - When to use: 判断市场行为是否真正转变
  - How: 阴线包含前一根蜡烛=OKR → 确认背景反转

- **威科夫50%原则**
  - When to use: 反弹/回调是否威胁趋势
  - How: 反弹不过50%=继续看跌（做空点）；回调不过50%=趋势未受威胁

- **破冰回测做空法**
  - When to use: 冰线被突破后
  - How: 破冰=CM不再防守冰线 → 回测冰层位置=做空点 → 价格深度下沉

- **JOC回测进场法（低量回测）**
  - When to use: JOC确认吸筹/再吸筹后
  - How: JOC后无量回测跳离点=进场点；放量回测=放弃，等新的二次测试

- **死角突破预期法**
  - When to use: 底部形成死角
  - How: 死角中需求>供应（上涨波量能>下跌波）→ 需求稍作努力即快速上涨；若支撑上反弹总是无力→准备震仓出逃

## Key Concepts

- **OKR（Outside Key Reversal）**：阴线包含前一根蜡烛，表示市场行为已经转变，是重要反转柱
- **威科夫50%原则**：反弹/回调超过50%则原趋势受威胁，不超过则属正常回调
- **失败的二次测试**：测试时成交量仍大+收盘低位+反弹乏力，表明供应未枯竭
- **破冰**：价格突破CM为派发设立的冰线，意味着CM派发完毕不再防守
- **再吸筹**：牛市中TR（震荡区）内出现Spring+SOS确认，表明不是派发而是再吸筹
- **吸收行为**：需求在阻力区吸收供应的价量表现，结束标志是JOC
- **V型反转**：无吸筹阶段的快速反转，此时小时图对识别吸筹尤为关键
- **灾难性止损**：放在需求起始柱（如JOC跳离柱）下方一个点的位置

## Mental Models

- 把每个案例的"预测→结果"对照当作复盘训练：第五章先思考，第六章看结果，训练判断力
- 把"判断"看作持续验证过程而非一次性结论：进场后每个蜡烛都在验证或证伪原判断
- 当信号与背景冲突时，把"市场倾向"作为最终裁判：不基于某个形态/指标
- 把CM的派发完毕看作"撤掉支撑"：破冰=CM不再保护冰线

## Anti-patterns

- **熊市抄底**："第二张图是熊市抄底的后果！"——供应背景下抄底必亏
- **放量回测时仍进场**：成交量大=供应未枯竭，必须等二次测试
- **见JOC就追，不等回测**：JOC后必须等低量回测，放量回测要放弃
- **反弹乏力仍持仓**：反弹成交量递减=需求匮乏，应减仓或出场
- **把无需求反弹当进场机会**：JOC支撑被突破后无需求反弹，价格继续下跌
- **供应背景下信任Spring**："卖盘控制的背景下，Spring经常失败，是做空信号"
- **忽视OKR反转信号**：OKR+卖盘跟随=背景转熊，不可心存侥幸

## Worked Example

**图四：JOC回测的二次测试序列**

背景：牛市中JOC后出现UT，浮动供应大，价格回落至JOC支撑位。

- **蜡烛1**（放量下跌破支撑）：反映市场倾向——逢高抛售，供应控制
- **蜡烛2**（回到JOC支撑）：成交量很大=供应未枯竭，**不符合进场要求**，耐心等二次测试
- **蜡烛3**（二次测试）：小成交量+小高低价差=供应枯竭，可先买一些，等需求出现再补仓
- **蜡烛4**（新的二次测试，灾难性止损放跳离柱下方一个点）：小成交量=持仓安全；次日阳线=需求吸收供应占上风
- **蜡烛5**（再次二次测试）：小量+高收盘=供应弱需求强；价格进入死角，需求稍作努力即快速上涨
- **蜡烛6**：突破死角，实现预期

要点：进场不是一次性事件，而是**测试序列**——每次测试不达标就等下一次，达标就分批进，全程用止损保护。

## Key Takeaways

1. **判断基于市场倾向，不基于形态或指标**——蜡烛的量能反映倾向，倾向决定方向
2. **二次测试可以多次出现**，耐心是核心美德；每次测试看"小量+小价差+高收盘"三要素
3. **OKR（阴线包含前根）是背景反转的硬信号**，配合卖盘跟随即确认熊市
4. **破冰后回测冰线是做空点**；冰线=CM派发完毕撤掉支撑
5. **JOC后低量回测=进场点；放量回测=放弃并等新测试**
6. **进场后每个蜡烛都在验证判断**：反弹乏力、量能递减、死角向下突破=出场信号
7. **牛市中TR内Spring+SOS确认=再吸筹**（非派发），牛市继续；反之UT+卖盘跟随=派发
