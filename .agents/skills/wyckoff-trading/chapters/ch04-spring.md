# 第四章：弹簧效应（Spring）交易法

## Core Idea

Spring是价格**向下突破支撑后迅速返回支撑上方**的"下跌停止行为"，其本质是用突破来**测试支撑附近的供应是否已被需求全部吸收**。突破时供应耗尽（小量小蜡烛）即可买，反弹无需求跟随立刻离场。

## Frameworks Introduced

- **Spring三分类法（按突破支撑时的力度+成交量）**
  - When to use: 每次价格突破支撑、可能形成Spring时
  - How:
    1. **第一类（震仓型）**：突破时蜡烛大、成交量放大 → 支撑处有大量卖单 → **不能进场**，等二次测试
    2. **第二类（标准Spring）**：突破时蜡烛和成交量都**大幅缩小** → 供应耗尽 → **可直接进场**
    3. **第三类（需测试型）**：突破时蜡烛和成交量**略微扩大** → 有供应但未压垮需求 → **必须等二次测试**缩量缩价差方可进场
    4. **第三类衍生成功型**：量大但**收在中点之上**（牛市中）→ 卖方努力被需求吸收 → 可直接进

- **Spring的六个位置清单**
  - When to use: 定位Spring出现的背景，决定可信度
  - How:
    1. 牛市震荡区底部 → 震荡区结束、牛市恢复
    2. JOC之后回测突破点时
    3. 回测垂直需求柱底部时
    4. 吸筹接近尾声时（CM制造恐惧收购便宜筹码）
    5. **熊市中出现 → 是陷阱，不能进场**
    6. 牛市中**连续失败的Spring → 预警信号**

- **Spring进场—验证—离场闭环（风控方法）**
  - When to use: Spring出现后到反弹确认全过程
  - How: ①进场前确认支撑是已建立的强支撑，止损放突破最低点 → ②进场后必须看到持续新高阳线+成交量随价格上涨递增 → ③若反弹无力（无需求跟随）→ **当机立断离场**

- **供应测试三件套（用于确认吸筹）**
  - When to use: 吸筹阶段判断是否真正进入牛市
  - How: 三个价格行为作为供应测试——**底部的震仓、Spring、顶部的JOC**。三者出现前耐心等待

## Key Concepts

- **Spring（弹簧效应/下冲反弹）**：价格迅速突破支撑后迅速返回支撑上方，本质是下跌的停止行为
- **震仓（Shakeout）**：Spring的特殊形式，发生在吸筹阶段右手边，长蜡烛+天量快速突破支撑
- **UT（上冲回落）**：与Spring镜像的上涨停止行为，需求试图冲高遇大量供应而回落
- **JOC（Jump Over the Creek）**：价格强力跳离震荡区，标志牛市恢复或上升准备完成
- **弹跳板（Springboard）**：回调中成交量和蜡烛非常小、供应耗尽的市场状态，随后通常出现JOC
- **垂直需求柱**：强力需求主导的放量长阳，其高点被突破即标志市场恢复牛市
- **二次测试**：对Spring的再次检验，成功的二次测试须是成交量与高低价差萎缩
- **努力与结果关系**：放量代表一方"努力"，蜡烛大小代表"结果"；高量对应小蜡烛=努力无结果

## Mental Models

- 当价格突破支撑时，把突破看作"对供应的体检"：量大=供应还在，量小=供应耗尽
- 把Spring反弹后的跟随走势看作"进场时机的考试"：通过=持续新高阳线+递增量；不通过=立刻离场
- 当Spring出现在熊市时，把它看作陷阱而非机会：背景（供应控制）> 形态
- 把"公众心理"当作反向指标：公众因恐惧不敢在突破支撑时动手，恰恰是聪明钱低成本进场处

## Anti-patterns

- **在熊市背景中找Spring抄底**：背景是供应控制，"熊市中Spring是陷阱，是无数抄底勇士的噩梦"
- **突破时成交量扩大却直接进场（第三类）**：必须等二次测试缩量确认
- **把高量大蜡烛的"第一类Spring"当机会**：那是支撑处存在大量卖单，价格会继续下跌
- **Spring后只看图形不看跟随**：反弹若无持续新高阳线+递增量，不立刻离场等于让亏损奔跑
- **在JOC处追高进场**："JOC进场属于追高，是情绪化的产物"；Spring是经过供求分析得到的信号
- **不看背景只看Spring形态**："Spring能否成功和背景有关"
- **刻意制造Spring**："没有出现，不要刻意去制造Spring，等待也是一种交易策略"

背景：区间震荡中的吸筹判断。

- **0号柱**：强有力需求柱+Spring柱+高量，买家付出极大努力反弹
- **1号（UT）**：高量长阴，供应扩大 → 0号买家应立刻出场；做空者可进场
- **3号（小型震仓）**：区间底部Spring，三大特点——成交量大、超长蜡烛、收于顶部（需求获胜）。可抄底，但**最好等低量二次测试**
- **5号**：3号小型震仓的低量测试 → **进场点**（量大幅缩小、高收盘=需求强劲）
- **7号（JOC/SOS）**：上升趋势准备结束，正式进入牛市
- **9号（关键Spring）**：确认小盘整是再吸筹而非派发；成交量大幅增长（卖方努力）但相对前一根长阴明显缩小（努力无结果）= 需求强劲吸收所有卖盘
- **10号**：需求过剩确认，牛市跟随形态=更高高点/低点/收盘价

要点：理想进场不是3号震仓本身，而是**5号的低量二次测试**；危机管理看9号之后是否阳线跟随。

## Key Takeaways

1. **背景优先于形态**：成功率高的Spring发生在上升趋势中；卖盘控制背景下不能用Spring进场
2. **突破瞬间的成交量是Spring的灵魂**：小量小蜡烛=可直接进；大量=必须等二次测试
3. **二次测试的合格标准是量价双萎缩**
4. **进场后必须看到跟随**：持续新高阳线+递增成交量；看不到立刻离场
5. **止损统一放在Spring突破的最低点**
6. **Spring与UT是镜像工具**：下降趋势中Spring经常失败，专业做空者利用此行为做空
7. **等待本身是策略**：不符合条件时不刻意制造，耐心等待SOS/SOW结束震荡区
