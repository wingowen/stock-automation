## Core Frameworks & Mental Models

### 三大原则（全书根基）

- **供求关系原则**：趋势动力来自供求不平衡。判断趋势方向、支撑/阻力有效性、反转可能性，全部以供求关系为理论基础。用价量关系找根据，理论根据成立才行动
- **因果关系原则**：趋势反转前必须有准备过程（吸筹/派发）。"因"=准备过程，"果"=趋势。没有"因"就不要追"果"——避免盲目抄底
- **努力和结果原则**：努力=成交量，结果=价格进展幅度。成交量扩大但价格范围很窄=努力没产生结果=停止行为。在支撑/阻力位最实用

### 看盘五步法

每次面对走势图时：①背景（牛/熊/震荡区）→ ②价量形态 → ③价量形态性质 → ④结论/预测 → ⑤措施和行动

### 吸筹四阶段（熊→牛）

1. PS→SC→AR→ST（熊市终止四行为）
2. 震荡区拉锯+疲劳战术（CM低价收购）
3. 测试供应（终极震仓/Spring，确认是吸筹）
4. SOS/JOC+测试（进入牛市）

**进场三位置**：①SOS/JOC后回测（最安全）②震荡区底部Spring ③终极震仓后二次测试

### 派发四阶段（牛→熊）

1. 初始供应→抢购高潮→自然回落→二次测试（牛市终止）
2. CM设派发区引诱公众（支撑夹板+媒体造势）
3. UT/SOW测试（确认派发——最重要阶段）
4. SOW出现，进入熊市

**做空点**：LPSY（SOW后小量小蜡烛反弹）、破冰后回测冰线遇供应

### Spring交易法

突破支撑时：量小蜡烛小=可直接进；量大=等二次测试；量大但收在中点之上（牛市）=可直接进。

**闭环**：进场（止损放突破最低点）→ 验证（持续新高阳线+递增量）→ 离场（无需求跟随立刻走）

**铁律**：熊市中Spring是陷阱，不能进场。背景优先于形态。

### 市场本质交易法

理论基础先行 → 价量确认为证 → 形成判断 → 交易计划+危机管理

**多时间框架**：日线看背景，小时线看细节（小时线提前反映日线反转）

### 关键思维模型

- 把技术指标当"表象"，供求关系当"本质"
- 把震荡区顶部看作"充满卖单的小溪"（JOC=跳越小溪）
- 把支撑看作"冰线"（破冰=CM撤掉护盘）
- 把CM看作"导演"（用媒体/急涨/震仓操控公众）
- 把"公众心理"当反向指标（公众恐惧时=聪明钱进场处）
- 把判断看作"确认链"（一个行为需另一个确认：PS→SC→ST→SOS→回测）
- 把震荡区判断看作"等右手边"（不预判，等SOS/Spring=吸筹，等SOW/UT=派发）
