# 速查表

## 决策规则

| 场景 | 行动 | 原因 |
|---|---|---|
| 熊市中看到Spring | **不进场** | 背景是供应控制，Spring是陷阱 |
| 震荡区左手边 | **不抄底** | 尚未经过二次测试确认 |
| 突破时立刻进场 | **不进** | 突破是公众行为，等小蜡烛低量回调 |
| SOS/JOC后 | **等缩量回测再进** | 需求可能无跟随 |
| 进场后放量阴线 | **立刻出场** | 遇到大量供应 |
| 上升趋势线被带量突破 | **无论盈亏离场** | 派发可能开始 |
| SOT出现 | **缩紧止损** | 需求开始匮乏 |
| 初始供应出现 | **缩紧止损+准备出逃** | 牛市可能到顶 |
| 死角形成 | **准备进场** | 行情即将大动作 |
| JOC后放量回测 | **放弃计划** | 供应未枯竭 |
| SOW后小量小蜡烛反弹 | **做空（LPSY）** | 最佳做空点 |
| 破冰后回测冰线遇供应 | **做空** | CM已撤掉支撑 |

## Spring三分类速查

| 类型 | 突破时特征 | 行动 |
|---|---|---|
| 第一类（震仓型） | 量大+蜡烛大 | 不进场，等二次测试 |
| 第二类（标准） | 量小+蜡烛小 | **可直接进场** |
| 第三类（需测试） | 量略扩 | 等二次测试缩量确认 |
| 第三类衍生 | 量大但收在中点之上（牛市） | 可直接进 |

## 二次测试合格标准

| 维度 | 合格 | 不合格 |
|---|---|---|
| 成交量 | 大幅缩小 | 仍大 |
| 高低价差 | 缩小 | 仍大 |
| 收盘 | 高位 | 低位 |
| 反弹 | 有力 | 乏力 |

## 50%原则速查

| 场景 | 回调<50% | 回调>50% |
|---|---|---|
| 牛市回调 | 趋势延续（蜡烛量缩小） | 趋势受威胁（扩量） |
| 熊市反弹 | 继续看跌（做空点） | 熊市可能恢复 |

## 震荡区方向判断

| 右手边信号 | 含义 | 行动 |
|---|---|---|
| SOS / Spring / 终极震仓 | 吸筹 | 做多 |
| SOW / 带量UT | 派发 | 做空/离场 |

| 优先级 | 位置 | 条件 |
|---|---|---|
| 1（最安全） | SOS/JOC后回测 | 小蜡烛+低成交量 |
| 2 | 震荡区底部Spring | 小幅突破可直接进，大幅须等二次测试 |
| 3 | 终极震仓后二次测试 | 缩量确认 |

## 止损位设置

| 场景 | 止损位 |
|---|---|
| Spring进场 | Spring突破的最低点 |
| JOC进场 | JOC跳离柱下方一个点 |
| 做空（LPSY） | LPSY反弹最高点上方 |
| 做空（破冰回测） | 冰线之上 |

## 跟随确认速查

| 信号 | 确认条件 | 失败条件 |
|---|---|---|
| Spring | 持续新高阳线+递增量 | 无需求反弹、无新高 |
| JOC | 低量回测+停止行为 | 放量回测 |
| SOW | 无量上涨确认 | 大量阳线递增=新需求 |
| UT | 放量下挫跟随 | 被市场吸收无跟随 |
| SOS | 缩量回测确认 | 放量阴线回测 |

## 供应/需求扩大识别

| 位置 | 需求扩大信号 | 供应扩大信号 |
|---|---|---|
| 震荡区 | 右手边长阳线+扩大量 | 顶部放量和上影线 |
| 熊市 | 天量+超长阴线=SC | — |
| 牛市 | — | 天量+超长阳线=BC |

## 停止行为识别速查

| 类型 | 特征 | 含义 |
|---|---|---|
| SOT | 突破幅度递减 | 需求减弱/供应压力增大 |
| 努力无结果 | 放量但价格进展小 | 该方向被对方吸收 |
| 放量滞涨/滞跌 | 牛市放量不涨/熊市放量不跌 | 走势即将停止 |
| 隐藏型停止 | 蜡烛大幅缩小但量大 | 卖方努力无结果=需求扩大 |

## 风控红线

1. **永远不在左手边抄底**
2. **进场后必须看到跟随**（持续新高阳线+递增量），否则立刻离场
3. **每个交易计划必须配套危机管理**——出场条件预先量化
4. **触发即执行**，不论亏赚
5. **没有终极震仓或SOS/JOC之一，不要抄底**
6. **趋势线被带量突破，无论盈亏离场**
