# 词汇表

**50%原则（50% Principle）** — 以上升/下降波幅度的50%为回调基准，未破=趋势延续，破=趋势受威胁 (Ch 3, Ch 5, Ch 6)

**bag holding（口袋接盘）** — 买方在下跌中张口袋接盘，表现为成交量扩大但价格跌幅很小 (Ch 5)

**BC（Buying Climax，抢购高潮）** — 上升趋势结束时公众因贪婪疯狂买入，天量创新高且上涨角度趋垂直，是CM派发的高峰 (Ch 1, Ch 3)

**冰线（Ice Line）** — 派发区底部支撑的形象比喻；破冰意味着CM不再防守，价格深度下沉 (Ch 1, Ch 3, Ch 5)

**死角（Dead Zone）** — 趋势线与水平阻力/支撑线交叉处，蜡烛高低点不断收敛，供求相持，突破后走势剧烈 (Ch 1, Ch 2, Ch 5)

**初始供应（Initial Supply）** — 牛市中首次出现大量供应上市的行为，仅为预警非牛市终结 (Ch 3)

**弹跳板（Springboard）** — 回调中成交量和蜡烛非常小、供应耗尽的市场状态，随后通常出现JOC (Ch 4)

**B** | 吸收行为（Absorption） — 需求在阻力区吸收供应的价量表现，结束标志是JOC (Ch 6)

**LPS（Last Point of Support，最后支撑点）** — SOS/JOC后缩量回调形成的最后支撑点，是安全进场点 (Ch 2)

**LPSY（Last Point of Supply，最后派发点）** — SOW之后小蜡烛小成交量的回测反弹点，最佳做空点 (Ch 3)

**CM（Composite Man，主力机构）** — 掌握大资金的人或机构，能移动市场，利用各种优势左右市场 (Ch 1, Ch 2, Ch 3)

**OKR（Outside Key Reversal，外部关键反转柱）** — 阴线包含前一根蜡烛，表示市场行为已转变，是重要反转柱 (Ch 6)

**PS（Preliminary Support，初次支撑）** — CM需求首次进场，以扩大成交量暂时阻止价格下跌 (Ch 2)

**SC（Selling Climax，恐慌抛售/超卖高潮）** — 下降趋势中潮水般的恐慌抛售，极宽振幅+超高成交量，标志下降趋势结束 (Ch 1, Ch 2)

**SOS（Sign of Strength，强势信号）** — 需求控制市场的强势上涨形态，长阳+明显增高成交量 (Ch 1, Ch 2)

**SOW（Sign of Weakness，弱势信号）** — 供应大举进入市场的弱势信号，放量长阴，须出现在右手边并经无量上涨确认 (Ch 1, Ch 3)

**SOT（Shortening of Thrust，突破幅度递减）** — 波峰/波谷之间突破幅度递减，是重要的停止行为 (Ch 1, Ch 2, Ch 3, Ch 5)

**Spring（弹簧效应/下冲反弹）** — 价格迅速突破支撑后迅速返回支撑上方，本质是下跌的停止行为，用于测试供应是否被需求吸收 (Ch 1, Ch 2, Ch 4, Ch 5)

**ST（Secondary Test，二次测试）** — 测试市场是否还有大型清仓行为，成功标准是蜡烛和成交量大幅缩小 (Ch 2, Ch 4)

**停止行为（Stopping Action）** — 牛市中放量滞涨、熊市中放量滞跌统称，是走势即将停止的信号 (Ch 1, Ch 5)

**JOC（Jump Over the Creek，跳离小溪）** — 价格放量长阳突破震荡区顶部供应区，是SOS的特殊形式 (Ch 1, Ch 2, Ch 4, Ch 5)

**AR（Automatic Rally，自动反弹）** — 恐慌抛售后的空头回补性反弹，不会持续，不可在此抄底 (Ch 2)

**UT（Upthrust，上冲回落）** — 价格突破阻力线后又收在阻力线之下，CM迅速吃掉空方止损单后任价格下跌 (Ch 1, Ch 3, Ch 4)

**无需求反弹（No-Demand Rally）** — 小蜡烛+小成交量+低收盘的反弹，买方无力，预示价格续跌 (Ch 5)

**吸收（Absorption）** — 需求在阻力区吸收供应的价量表现，结束标志是JOC (Ch 6)

**吸筹（Accumulation）** — CM在震荡区收购公众恐慌抛出的股票的建仓过程，分四阶段 (Ch 2)

**派发（Distribution）** — CM在高位将吸筹阶段买入的股票卖给公众的过程，分四阶段 (Ch 3)

**疲劳战术（Fatigue Tactics）** — CM在震荡区中用冗长枯燥走势折磨公众心理，迫使公众割肉 (Ch 2)

**跟随（Follow-through）** — 停止行为/SOT/Spring后下一根蜡烛的方向与量能，决定信号是否成立 (Ch 5, Ch 6)

**再吸筹（Re-accumulation）** — 牛市中TR内出现Spring+SOS确认，表明不是派发而是再吸筹，牛市继续 (Ch 6)

**震仓（Shakeout）** — CM突然压低/抬高价格甩掉公众，分普通震仓和终极震仓。终极震仓是吸筹结束的信号 (Ch 1, Ch 2, Ch 4)

**供应线（Supply Line）** — 下降通道的上轨，假设每次价格到此处都有大量卖单流入压价 (Ch 1)

**垂直需求柱/垂直供应柱（VSB）** — 垂直需求柱=放量长阳，底部形成支撑区；垂直供应柱=供应完全控制市场 (Ch 1, Ch 4)

**灾难性止损（Catastrophic Stop）** — 放在需求起始柱（如JOC跳离柱）下方一个点的位置 (Ch 6)

**V型反转（V-Reversal）** — 无吸筹阶段的快速反转，此时小时图对识别吸筹尤为关键 (Ch 6)
