## 第⑤步：措施和行动

基于前四轮的完整分析，现在制定具体的行动计划。

### 分析要求

1. 定义进场条件（什么情况下可以买入）
2. 定义放弃条件（什么情况下不进场或离场）
3. 定义跟进条件（持仓中如何管理）
4. 所有价位必须具体、可执行

### 输出 JSON Schema

```json
{
  "entry_conditions": {
    "scenario": "进场场景描述",
    "price_range": {"low": 0.0, "high": 0.0},
    "volume_requirement": "量能要求描述",
    "confirmation_signal": "确认信号描述"
  },
  "abandon_conditions": {
    "scenario": "放弃场景描述",
    "break_level": 0.0,
    "reason": "放弃理由"
  },
  "follow_up_conditions": {
    "add_position": "加仓条件描述",
    "take_profit": {"level": 0.0, "description": "止盈描述"},
    "trailing_stop": 0.0,
    "time_stop": "时间止损描述"
  },
  "position_size": "1/3仓|1/2仓|空仓",
  "risk_reward": {
    "risk": 0.0,
    "reward": 0.0,
    "ratio": 0.0
  },
  "action_summary": "一句话总结行动建议"
}
```

### 注意

- 进场价位区间必须与第④步的支撑位一致
- 止损价（break_level）必须与第④步的关键价位一致
- 仓位建议保守，宁可不进也不要重仓
- 如果背景不支持（如熊市中的 Spring），action_summary 应明确建议"观望"
