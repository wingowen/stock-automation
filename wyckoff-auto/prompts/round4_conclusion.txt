```json
{
  "background_conclusion": "大背景结论（1-2句话）",

  },

    "deviation": "偏差分析",

  }
}
```

### 输出要求

- 只输出一个 JSON 对象，严格匹配 schema；不要任何解释文字或 ```json 代码块标记。
- 所有字段必须出现；无历史简报时 `has_history` 填 false，其余历史字段填空字符串 ""。
- `direction` 与 `prediction.direction` 必须使用同一套取值（bullish|bearish|neutral）并保持完全一致。
- `resistance` / `support` 及扩展价位必须来自 K 线数据中的实际价格节点，禁止编造。
- `confidence` 要诚实评估：逻辑链不完整或数据不足时标 "low"，不要为迎合方向而拔高置信度。
- 若有历史简报，必须在 `history_comparison` 中对照上次预判进行迭代验证，提炼可复用的教训。
