## 本轮任务：背景判断

基于用户提供的 K 线数据，判断该股票当前的大背景。

### 分析要求

1. 判断当前处于牛市、熊市、还是震荡区
2. 如果处于震荡区，判断是吸筹（accumulation）还是派发（distribution）
3. 判断处于吸筹/派发的哪个阶段（A/B/C/D/E）
4. 识别趋势方向和关键趋势线

### 输出 JSON Schema

```json
{
  "background": "bull|bear|trading_range",
  "background_reasoning": "2-3句话说明判断依据",
  "phase": "accumulation|distribution|spring|none",
  "phase_stage": "A|B|C|D|E|none",
  "phase_reasoning": "阶段判断依据",
  "trend": "up|down|sideways",
  "trend_description": "趋势描述",
  "key_levels": {
    "support": 0.0,
    "resistance": 0.0
  },
  "trading_range": {
    "exists": true,
    "high": 0.0,
    "low": 0.0,
    "duration_days": 0
  }
}
```

### 注意

- 所有价格数字必须来自 K 线数据，禁止编造
- 背景判断是后续所有分析的基础，务必准确
- 如果数据不足以判断，phase 填 "none" 并说明原因
