本轮为「看盘五步法」第①步：背景判断。

基于用户提供的 K 线数据，判断该股票当前的大背景。这是后续所有分析的基础，务必准确。

### 分析要求

1. 判断当前处于牛市（bull）、熊市（bear）还是震荡区（trading_range）。
2. 若处于震荡区，判断是吸筹（accumulation）还是派发（distribution）。
3. 若处于吸筹/派发，判断所处阶段 A/B/C/D/E。
4. 识别趋势方向与关键趋势线（支撑/阻力）。

### 字段语义提示

- `phase` 仅在震荡区背景下有意义；bull/bear 背景直接填 "none"。取值：accumulation | distribution | spring | none。
- `phase_stage` 仅吸筹/派发有效；否则填 "none"。
- `spring` 是一种发生在吸筹末期的特殊事件，不要把它当作独立的长期背景。
- 示例：长期下跌后低位横盘、出现 SC/AR → phase="accumulation", phase_stage="B"。

### 输出 JSON Schema

```json
{
  "background": "bull|bear|trading_range",
  "background_reasoning": "2-3句话说明判断依据（引用具体价格/量能事实）",
  "phase": "accumulation|distribution|spring|none",
  "phase_stage": "A|B|C|D|E|none",
  "phase_reasoning": "阶段判断依据",
  "trend": "up|down|sideways",
  "trend_description": "趋势描述",
  "key_levels": {
    "support": 0.0,
    "resistance": 0.0
  },
  "trading_range": {
    "exists": true,
    "high": 0.0,
    "low": 0.0,
    "duration_days": 0
  }
}
```

### 输出要求

- 只输出一个 JSON 对象，严格匹配上方 schema；不要任何解释文字、前言或 ```json 代码块标记。
- 所有字段必须出现；无法判断的字段填空字符串 "" 或 null，不要省略字段。
- `support` / `resistance` / `trading_range` 的价格数字必须来自 K 线数据中的真实节点，禁止编造。
- 如果数据不足以判断，phase 填 "none" 并在 phase_reasoning 中说明原因。
