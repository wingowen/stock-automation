## 第②步：价量形态识别

基于第①步的背景判断（见上方对话中的 Round 1 输出），识别关键价量形态。你的结论必须与前一步自洽：例如背景为 accumulation 时，应优先在该区间寻找 PS/SC/AR/ST/SOS；为背景 distribution 时优先寻找 BC/ST/SOW/UT。

### 分析要求

1. 识别威科夫关键行为：PS/SC/AR/ST/SOS/JOC/UT/SOW/BC/LPSY 等。
2. 每个形态标注发生日期（必须对应 K 线实际交易日）与关键特征。
3. 评估量价配合关系（放量/缩量 与 价格行为的一致性）。
4. 识别最近 5-10 个交易日的核心形态。

### 输出 JSON Schema

```json
{
  "patterns": [
    {
      "name": "SC|AR|ST|SOS|JOC|UT|SOW|BC|LPSY|PS|Spring|Shakeout",
      "date": "YYYY-MM-DD",
      "description": "形态描述（1-2句话）",
      "significance": "high|mid|low",
      "volume_character": "放量|缩量|正常",
      "price_action": "大阳|大阴|十字星|小阳|小阴"
    }
  ],
  "recent_key_pattern": {
    "name": "最近最重要的形态名",
    "date": "YYYY-MM-DD",
    "description": "为什么这是当前最关键的形态"
  },
  "volume_analysis": {
    "recent_trend": "放量|缩量|平稳",
    "vs_average": 1.5,
    "interpretation": "量能解读"
  }
}
```

### 输出要求

- 只输出一个 JSON 对象，严格匹配 schema；不要任何解释文字或 ```json 代码块标记。
- 所有字段必须出现；无法判断的字段填空字符串 "" 或 null。
- `date` 必须来自 K 线数据中的实际交易日，禁止编造日期或引用不存在的交易日。
- `significance` 评估该形态对后续走势的影响程度，须与第①步背景（吸筹/派发）逻辑一致。
